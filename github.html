TransformerAGNews 📰

Deep Learning

Implémentation from scratch d'un encodeur Transformer pour la classification de sujets de presse sur le dataset AG News. Classification automatique des articles dans 4 catégories : Monde, Sport, Business et Science/Technologie.

Python 3.9 PyTorch Transformer (Encoder) AG News Dataset Tokenization Multi-Head Attention Positional Encoding Jupyter Notebook
  • 📊 Dataset AG News : 120 000 échantillons d'entraînement et 7 600 de test, répartis en 4 classes (Monde, Sport, Business, Sci/Tech)
  • 🧠 Implémentation "from scratch" de l'encodeur Transformer avec PyTorch
  • 🔧 Composants clés : Multi-Head Self-Attention, Feed-Forward Network, Positional Encoding, Layer Normalization
  • 🎯 Précision de validation d'environ 91.9% sur le jeu de test AG News
  • 📈 Visualisation des mécanismes d'attention pour interpréter les décisions du modèle
  • 💾 Sauvegarde des poids du modèle entraîné pour inférence rapide
  • 🔮 Prédiction en temps réel sur de nouveaux articles de presse
  • 🏗️ Architecture modulaire : src/, notebooks/, models/, data/
